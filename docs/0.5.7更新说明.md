# 0.5.7 更新说明

日期：2026-09-30。此版本包含之前尚未提交的 0.5.x 同名素材整理功能及兼容修复。

## 紧凑面板

- 状态与暂停同一行，两种整理操作并排，统计合并为一行。
- 录音详情、工程与目录默认收起，展开后保留完整名称、路径和处理阶段。
- 缺少工程或序列时展开连接信息；录音处理失败时展开详情。相同状态的更新保留用户手动选择。
- 最近活动最多 20 条，限高 168px 并独立滚动；主面板保持文档流，避免内容互相挤压。
- 扫描预览清单、风险说明分别滚动，底部操作保持可见。
- 默认停靠高度为 480px，浮动高度为 520px，最小尺寸仍为 300×360。
- 刷新、清空和展开采用 Lucide 图标，附许可证。

## 同名素材整理与修复

- 仅递归扫描当前工程的项目面板及子素材箱，跳过序列和字幕样式等非媒体条目。
- 完整文件名相同、路径不同的普通音频、视频和静态图片先预览再确认，在原目录改为唯一名称。
- 同一来源的多个素材项一起同步名称和链接，不逐条改写时间线片段名，不逐文件保存整个工程。
- 与录音“扫描遗漏”共用重链接、刷新及明确在线状态读回。
- 手动整理以分块 SHA-256 核对改名前后内容，兼容 exFAT 文件编号、创建时间随改名变化；自动录音同盘流程不增加该读取。
- 使用无覆盖移动，改名前持久化映射和内容校验，失败时尝试恢复。恢复不完整或记录失败时停止后续。
- 普通素材不加入录音自动回收；离线、代理、图片序列、关联文件、链接目录等不确定情况保留并说明原因。

详细操作与限制见 [同名素材整理](同名素材整理.md)。

## 验证边界

- 256 项自动测试通过，构建控件、脚本顺序和源码/产物哈希一致性通过。
- 300×360、360×480、420×680 三档尺寸共 18 个合成状态的生产 HTML/CSS 浏览器预览通过；展开、键盘收起、清空和长记录滚动已检查。
- Windows 与 macOS 安装包已完成清单及 ZIP 读回校验；Windows 本机安装文件已核对。
- 浏览器预览、模拟宿主和安装成功不等于真实 Premiere 工作流验收。真实录音、媒体重链接、回收联动与 macOS 实机仍待临时工程确认，保持 `runtime_tested=false`。
- 本次上传不包含私人工程、素材、桥接凭据、恢复备份或本地安装日志。未创建正式 Release。
